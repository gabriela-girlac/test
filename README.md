#Proiect HTML
#Despre proiect
Acest proiect reprezintă începutul dezvoltării unei pagini web folosind limbajul HTML. 
#Caracteristici
Structura de bază a unei pagini HTML
Declararea tipului de document
Configurarea caracterelor și a dimensiunii paginii
Definirea titlului paginii
Utilizarea secțiunilor HEAD și BODY
#Scopul proiectului
Familiarizarea cu elementele fundamentale ale limbajului HTML și pregătirea pentru dezvoltarea unor pagini web mai complexe.
